# 变量、锚点与传导判断

## 四个不同概念

- Event：来源记录的发生、声明或计划，保留时态及对象。
- Fact Signal：Event 支持的某变量在某自身锚点上的变化记录，不是投研结论。
- 锚点影响：Codex 对业务、经济或风险机制的判断，可能为 direct 或 inferred。
- 投研结论：升温、降温、分化；证据不足时不判定方向。不是交易指令。

## 变量综合工序

1. 按真实 entity_id + variable_id 分组，再识别产品、地域、统计口径和时间可比性。同名不等于同变量，不同锚点不合并。
2. 阅读所有来源 Event/Evidence，核对信号内容是否真能支持该变量；判断实际/计划、有效期、来源独立性、时序和适用对象。
3. 同向可比信号形成一条综合判断，原文分别作为证据；转载去重的是证据权重，不丢弃原始 ID。不同产品/同比环比不能因方向相同就隐藏范围。
4. 方向相反时比较内容与经济机制，不按条数、百分比分数或固定权重决胜。可以判断仍升、仍降、基本平稳、分化或未明确。只有有根据支持相抵后的稳定才用平稳；缺数据不是平稳。不同对象作用相反通常是分化，无法判断净作用是未明确。
5. 记录 synthesis 和 conflict_resolution，说明主导证据、反向证据为何没有推翻或为何无法取舍。把计划方向与已发生结果分开。
6. 每条自身信号在一个 scope/timeframe 组中归入 support、counter 或 excluded，三组互斥且完整覆盖；分组至少有一条自身信号。excluded 仅用于错挂/失效/口径不适用等，不能为了得到统一结论排除真正反证。
7. 原始 source_direction、signal、引用原样保留；综合 direction 独立。例如源标签“上升”但文本描述安全恶化，综合可判断安全下降并解释，不改写源标签。

示例只解释方法，不是本次数据：已公布利率不变与政府希望降息共存，实际利率综合为平稳，诉求不等于已降息；同比下降与环比回升不精确抵消；不同药品获批与试验失败分产品保留，不能合成同药品“无变化”。

## 直接与推理

有本路自身 Signal 的实体必须给 direct 判断，包括全为不适用信号导致未明确。direct 表示判断来源位置，不表示信号可靠、结论确定或影响已经发生；同时有传导因素时在依据中表达，不改成 inferred 隐去自身信号。

无自身 Signal，但有本路 Event 或上游判断能支持机制时为 inferred；其自身 variable_signals/variable_assessments 为空，不复制上游信号。每条传导记录根 Event/Evidence、上游实体及 local_key（合同允许且同单元可闭合时）、机制、成立条件、方向和时滞。引用其他工序的 local_key 不合法。

结构边只证明投入、组成、依赖或业务挂接；影响方向需判断。没有供应替代、采购敞口或传价证据时表达条件，不将一般经济学原理写成已观测结果。不要求每次传导必须走完整“政治→经济→产业”，允许有证据的直接渠道；不能仅为填层级而制造宏观锚点。

## 方向、影响度和置信度

| 项目 | 判断依据 |
| --- | --- |
| 变量 direction | UP 上升、DOWN 下降、STABLE 平稳、MIXED 分化、UNKNOWN 未明确，针对指定变量和范围 |
| 投研 assessment.direction | warming 升温、cooling 降温、diverging 分化、pending 不判定方向，针对锚点基本面与研究结论 |
| 影响度 high/medium/low/pending | 影响幅度、业务覆盖、持续期、核心约束及兑现条件；不用信号数量代替影响度 |
| 置信度 high/medium/low 或合同允许的空值 | 来源质量、证据一致性、对象匹配、机制完整性和关键缺口；与影响大小分开 |

高影响需有核心业务/广泛暴露或持续约束的实质依据；中影响为范围或持续性有限但可解释；低影响为较窄、间接或较弱作用；无法确定影响程度用 pending 并解释。预期后果可能重大但证据弱时，允许高影响/低置信度，必须写明条件。不能把“不知道”降格为低影响。

反证是来源支持的相反事实；缓冲区分来源事实、推理和假设；证据缺口是待验证项，不冒充反证。无反证只写未识别到，不表示已证实。最终结论需同时说明主导机制、分化范围及可能改变判断的条件。

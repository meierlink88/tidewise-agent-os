# v8 定稿归档

用户于 2026-09-07 确认本版报告定稿。阅读入口：[报告](report.html)。

本目录原样保存已审阅的报告、结构化数据、字段定义、Schema、审计结果与生成脚本。`archive-checksums.json` 记录归档原件 SHA256；旧预览保留可用。此前 README 中的“审核”“提议”属于形成过程记录，以本定稿说明确认报告基线状态。

定稿范围是报告内容、展示与字段设计。`report-publication/v5-draft` 是本版数据中的草案标识，定稿不代表 Data Service 已支持、已经发布或原生 Workflow 已能生成本版。后续服务合同实现另行交付。

变量信号在详情的各自实体下展示为“变量｜方向｜信号”，信号采用来源记载文本，限定及溯源折叠展示。有自身可采用信号的判断标记直接，有支持的传导判断标记推理；没有判断的节点不进入报告。

归档脚本作为生成过程留存：`render_v8.py` 读取本目录数据；`build_v8.py` 与 `validate_v8.py` 还依赖原预览父目录的冻结输入及 v7 文件，本归档未打包这些大型输入，不能将其视为独立可重跑的 Workflow。已有源输入摘要保留在 manifest.json。本次归档验证了报告 JSON 对本目录 Schema 的符合性和所有归档原件的字节一致性。
